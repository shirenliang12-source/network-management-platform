# 1.9.53 安装适配候选（未完成 Windows PG 端到端验证）

此候选不能替代已交付的 1.9.52 SQLite 修复版用于直接生产升级。

HTTPS 向导：勾选后生成独立 RSA 私钥和一年期自签名证书，保存到原数据目录 managed 子目录。
证书包含 localhost、127.0.0.1、::1 和安装电脑的主机名；通过 IP 访问需要在维护命令中额外指定 --tls-name。
客户端必须由管理员配置证书信任。安装器不自动安装根证书、不关闭证书校验。
健康检查使用实际服务环境、端口和证书；快捷方式使用 HTTPS。证书在后续升级保留，过期时要求先续期。

PG 构建使用 `python installer/build_installer.py --with-pg`，输出独立 pg-preview 安装包。
归档来源为 EDB 官方 Windows PG 15.19 下载，构建锁定 SHA-256；包含服务器组件及许可文件，不包含 pgAdmin。
安装向导的 PG 选项默认不选。选择后拟执行：停止应用、创建独立服务 CiscoNetworkManagerPG、
数据存放 ProgramData/CiscoNetworkManager/postgresql/15/data，端口 54329，仅监听 127.0.0.1，
生成独立随机管理与应用密码（应用账号不是超级用户），使用 SCRAM 认证。
原 SQLite 不删除，在受保护的迁移目录生成快照、升级快照结构、复制到空 PG、逐表核对行数和哈希后才切换配置。
端口占用、来源关系错误、已存在未知 PG 服务/数据目录、迁移失败时拒绝自动覆盖，保留数据供恢复。
重大版本升级不自动覆盖原 PG 二进制。

重要限制：当前电脑的 Windows 应用控制阻止官方 PG 的 initdb.exe（WinError 4551）。
PG 服务注册、账号权限、SQLite 实际迁移、重启恢复尚未完成端到端验证，不得声明已通过。
卸载保留数据库目录、恢复凭据及 PG 二进制/服务；后续数据库清理需单独确认。
升级失败时恢复应用运行配置，但已创建的 PG 数据不删除；再次尝试需先由管理员核对残留状态。
