# v1.9.55：v1.9.54 安装修正版

保留 v1.9.54 功能修复；不覆盖此前发布的安装包。此前提供的 service.log 仅包含 v1.9.52 正常运行和停止记录，尚不能证明唯一故障原因。

本包移除原生 NSIS 安装器健康检查/HTTPS 准备/访问地址查询的 PS1 启动依赖，改由程序直接执行，并读取现有服务的环境、端口和数据目录。仍严格检查实际运行版本与 HTTPS 证书，不绕过系统应用控制。
修正首次选择不同安装盘符时默认数据目录的解析时机。
服务启动退出码、每次健康检查输出及回退启动结果保存到安装目录 upgrade-diagnostics.log；不再仅显示笼统的启动失败。

## 升级

1. 在正常运行的 1.9.52 上备份平台数据，另存到安装目录之外。
2. 保持原安装路径和数据目录，直接覆盖升级，不先卸载。
3. 首次验证建议不新增 HTTPS；已有 HTTPS 配置不清除。
4. 若失败，保留原数据，并提供 upgrade-diagnostics.log 和 service.log。

本包不捆绑 PG、不自动迁移 SQLite。PG 拦截保护已在源码修复，但未签名 PG 的执行仍须系统策略批准。
真实生产服务覆盖安装未在本机执行；独立测试不替代目标电脑验证。设备支持范围见 DEVICE-SUPPORT.txt。
