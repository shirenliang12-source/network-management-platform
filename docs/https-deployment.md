# HTTPS（源码配置阶段）

程序支持通过 NETMGR_SSL_CERTFILE 和 NETMGR_SSL_KEYFILE 指定 PEM 证书链与私钥。
两项必须同时填写。证书应包含实际访问的 DNS 名或 IP 的 SAN，建议由公司内部 CA 签发并让客户端信任该 CA。
启用后同一监听端口仅提供 HTTPS，登录 Cookie 自动启用 Secure；证书无效时启动失败，不降级为 HTTP。
未配置时保留原 HTTP 行为。此功能没有自动生成证书或自动跳转 HTTP。

证书和私钥放在程序目录之外，限制私钥读取权限为运行服务的账号和管理员，不要提交到 Git。
通过服务配置传入上述环境变量，并在重启前确认客户端证书信任和访问地址。

当前 Windows 安装器仍使用 HTTP 健康检查，Docker 默认健康检查也尚未适配 HTTPS。
因此此阶段不要在已安装生产服务上启用；待安装器、健康检查及实际 TLS 握手回归完成后再部署。
