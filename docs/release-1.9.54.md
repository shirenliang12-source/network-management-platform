# Windows v1.9.54 升级说明

本包包含当前设备适配、服务器 IP 表头和关联反查修复，以及此前 IPAM 导入、配置预览、多 vCenter 等迭代修改。

## 安装前

1. 在现有平台执行应用数据备份，将备份另存到安装目录之外。
2. 记录当前安装路径、端口和数据目录；原目录覆盖升级，不要先卸载。
3. 不要同时启动新旧版本访问同一数据目录。

本次不捆绑 PostgreSQL 服务，不自动将 SQLite 转换为 PostgreSQL；原有数据库连接配置保持。内置 PG 迁移仍待实机验证，不属于本包交付内容。
安装器提供可选 HTTPS，默认不启用；自签名证书需要客户端信任，既有证书配置应保留。建议先维持原访问方式，确认升级成功后再启用 HTTPS。
安装器不随包覆盖 commands.json、数据库或运行密钥。已自定义的命令保留，不强行覆盖成新默认模板。

## 本轮重点

- 修复服务器存储 IP 表头与 U 位错位，补齐 IPAM、服务器、机柜和设备反查。
- 带掩码的导入 IP 按主机地址匹配；同 IP 多设备不自动猜测归属。
- ASA/FTD 区分 SSH 认证和 CLI 提权失败；失败不直接将设备标为离线。
- 扩充 WLC、路由器、自主 AP、Gaia 类型和能力提示。
- 电话、CUCM、轻量 AP 默认仅登记，不声称已完成专用登录与完整备份。
- LLDP 支持更多输出格式；未知输出/权限失败保留历史邻居。
- Check Point Expert LLDP 需显式配置命令和独立 Expert 密码。

完整设备能力边界见随包 DEVICE-SUPPORT.txt。离线回归和打包启动检查不等同于所有型号实机验证。
本包未进行生产服务覆盖安装测试；建议先在测试电脑或副本数据上验证后升级。
