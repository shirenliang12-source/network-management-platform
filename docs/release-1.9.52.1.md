# 1.9.52.1 升级验证版

基于恢复的 1.9.52，保留 SQLite；不自动安装或迁移 PostgreSQL。

## 功能

- ASA/FTD 会话处理、WLC/IOS 路由器/自主 AP 类型，Fortinet/PA 采集、LLDP 和文本配置备份适配。CUCM/电话/轻量 AP 仅登记，完整备份未实现；设备能力以权限及固件实机验证为准。
- 服务器 IP 表头与设备/IP/机柜反查修复。
- 超级管理员导入 PEM 证书及私钥，支持私钥密码、匹配/有效期校验、受限目录保存；导入后管理员择时重启服务。
- 升级保留服务身份、启动参数、数据库、密钥、证书；停止超时中止覆盖，不批量终止其他 NSSM 服务。
- 健康检查支持 HTTP/HTTPS，核对版本并固定验证本机服务证书指纹。程序恢复失败不会宣称回滚成功。

## 安装前

1. 在平台创建应用数据备份并离机保存；备份实际数据目录（包括密钥和 tls 目录）。复制运行中的 SQLite 文件不等于一致性备份。
2. 使用原安装目录，不先卸载、不更换数据目录。示例：程序 D:\renliang\Cisco\Cisco Network Manager；实际数据 D:\renliang\Cisco。
3. 等待备份/采集任务结束后执行安装。如果服务长期 STOP_PENDING，本包会中止；处理旧服务或重启 Windows 后再试，不要反复覆盖。
4. 安装后检查 /health 版本为 1.9.52.1，并核对设备、账号、配置、备份及证书。启用 HTTPS 时使用 https://原地址:原端口。
5. 若 Windows 应用控制阻止执行，请由管理员审查签名/策略，不要关闭安全策略或绕过限制。

## 验证边界

121 项 Python 回归测试、12 项前端测试通过。打包 EXE 的 43 项隔离功能检查通过，含旧库迁移保留与 IPAM 去重。真实 Windows 私钥目录保护、导入证书后的两次 HTTPS 启动、证书保留及版本拒绝检查通过；HTTP/HTTPS 探测含证书不匹配拒绝测试。

未在用户那台旧服务器实测 Windows 服务覆盖升级和回滚。原生服务停止流程已编译及静态检查，未操作本机生产服务。本版本标记为预发布/升级验证版，不替换原始 1.9.52 稳定包。程序回滚不等于数据库自动降级；原数据库和备份不自动删除。
