# 基于 1.9.52 的 ISP 线路迭代

独立于 1.10 开发目录。未修改原始安装器、服务停止流程或生产数据。

入口：ISP线路。管理员默认可见，普通用户需要授予“ISP线路”模块权限。

维护运营商名称、线路编号、多个 CIDR 网段、已用 IP、预留 IP、
可编辑的使用位置/用途和使用说明。支持查询、编辑、确认删除。
同一运营商和线路编号不能重复（忽略大小写和首尾空白）。

可用总数按网段计算，剩余可分配=可用总数-已用-预留。
IPv4 /31 和 /32 不扣地址，其余排除网络和广播地址；
IPv6 /127 和 /128 不扣地址，其余排除子网首地址。
同一线路重复网段/IP去重，重叠网段、越界地址、已用与预留冲突拒绝保存。
不会枚举整个网段；IPv6容量返回十进制字符串，避免前端精度丢失。

自动按线路CIDR读取IPAM地址：使用中计已用，预分配计预留，规划/已停用不占用。
与手工台账按标准IP去重，已用优先于预留；自动关联只读，不回写手工输入或IPAM。
列表刷新和保存时重新统计。需IPAM模块权限，否则明确显示仅手工统计，不泄露IPAM数据。
带掩码IP会规范化，无效、越界和网络/广播地址不计入；编辑页展示自动关联地址。
不同线路可以有相同网段，统计按线路独立计算，不汇总为全局唯一地址数。
使用率是IP已用比例，不是带宽流量。

升级只新增 isp_lines 表，沿用原有数据库备份和 Alembic 迁移机制。
安装前仍须备份完整 data 目录。此源码迭代尚未打包或部署到生产服务。
