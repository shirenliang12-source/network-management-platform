# v1.9.52.8 Windows 模块内容体验优化版

此版本供现有 SQLite 安装升级；不自动迁移 PostgreSQL、不内置 PG 服务，不自动启用 HTTPS。
沿用已保存的数据目录、数据库、配置及加密密钥。升级前请在平台创建应用数据备份，并另存整个数据目录。
不要卸载后重装；在原安装位置执行升级。安装程序执行新版本健康检查。

修复 IPAM 聚合、网段、IP 地址页切换后导入类型未更新的问题。
IP 地址清单仍使用原有去重导入规则，重复项跳过而不覆盖；本版本不会自动清理历史重复记录。
包含 UTC 时间显示修正、备份失败不直接判离线、分页配置预览、服务器存储 CSV 导入导出，以及 vCenter 导入状态筛选和多连接配置。

本次补齐：

- 全部业务页面使用统一企业级视觉系统，重新整理导航层级、页面标题、卡片、统计指标、表格、筛选栏、表单、按钮和弹窗。
- 新增侧栏功能搜索、移动端抽屉导航、粘性顶栏、当前页面提示、运行状态提示，以及打印和减少动画模式。
- 登录页与403权限页重新设计；动态表格与弹窗补充键盘操作和可访问性属性，不改变原有接口及数据结构。
- 每个模块增加针对本业务的管理目标、三个关键信息范围和页面内内容导航，不再只有导航栏变化。
- 所有数据表增加当前可见记录数量；筛选区与结果区明确分层。信息更完整但不增加数据库字段和明细列。
- 新增“大屏驾驶舱”入口，面向1920×1080综合展示设备健康、备份与变更、地址容量、虚拟化、线路、机柜资产和同步状态。
- 驾驶舱支持自动刷新、手动刷新、暂停和浏览器全屏，按当前账号权限读取数据，未授权模块不会越权展示。

- 配置备份页直接维护全局保留数量和每台设备独立保留数量；0 表示全部保留，留空继承。
- 备份失败告警支持一键全选、批量确认、批量删除；删除告警不删除原任务和审计记录。
- 设备管理新增机柜、起始 U 位、占用 U 数，自动校验越界及网络设备/服务器/存储冲突，并在数据中心机柜视图反查。
- vCenter 清单默认读取最多 2000 项；关机、挂起、模板和其他状态不再因 Guest Tools/可选配置字段不可读而丢失，并提供独立状态统计和筛选。
- 数据库迁移会把旧版 U13-14 等文本位置转换为结构化 U 位，保留历史关联。
- ISP线路新增UTF-8/GB18030 CSV一键导入和UTF-8 BOM导出；按运营商+线路编号去重，可选择跳过或明确覆盖。
- ISP线路新增公司、功能、区域三级自定义分组，带宽Mbps、独立用途和独立使用位置字段及组合筛选。
- ISP清单上方新增可持久化自定义仪表盘，默认展示线路数量、用途分布和使用位置分布。

服务器存储 CSV 请下载模板填写；name、site、rack 分别是名称、已有站点名、已有机柜编号。
additional_ips 为 JSON 字符串数组；名称、序列号、资产编号或 IP 冲突时跳过并列出记录 ID。
不要把本安装包当成已完成的 SQLite→PG 迁移版本，也不要在服务中设置新增 HTTPS 变量；相关安装适配仍未完成。
